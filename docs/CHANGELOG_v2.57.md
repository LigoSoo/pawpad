## 1. 왜

사용자 지적: 문서의 "함정"은 한글이지만 일상에서 이 뜻으로 쓰지 않아, 문맥을 봐도 무슨 뜻인지 유추할 수 없다.

같은 종류의 표현을 전수 조사했다(후보 약 35개). 기준은 사용자 결정에 따라 **평소 업무·개발 대화에서 실제로 쓰는 말은 유지, 문맥을 봐도 뜻이 안 잡히는 말만 교체**.

## 2. 교체표

| 이전 | 이후 | 쓰이던 뜻 |
|---|---|---|
| 함정 | 주의사항 | 코드만 읽어서는 모르는데, 모르고 고치면 다시 작업하게 되는 점 |
| 스윕 | 누락 점검 | 빠진 기능이 없는지 훑어보기 |
| Codex 표면 / 표면별 | Codex용 파일 / Claude용·Codex용으로 | AGENTS.md · .agents/skills · .codex 묶음 |
| 투영 | 옮겨 그리기 / 시각화 / 표시 | PRD-tree 내용을 화면 시안으로 옮기기 |
| 비대 | 커짐 / 길어짐 / 낭비 | 문서·파일·context가 쓸데없이 불어남 |
| 횡단 import | 기능 간 내부 import | 다른 기능 폴더의 내부 파일을 직접 참조 |
| hoist | 상위 폴더로 올리기 | 공통 코드를 쓰이는 범위에 맞는 폴더로 이동 |
| 가산적 | 추가 위주 | 기존 것을 고치지 않고 더하는 방식 |
| 응집 | 한 폴더에 모으기 / 둠 | 관련 파일을 같은 폴더에 둠 |
| 첨자 | 단계 표시 | Active Skills 줄의 스킬 이름 뒤 진행 표시 |
| 앵커 | 줄 맨 앞에서 시작 / 링크 | Retrieval 선언 인정 조건 / 목업의 화면 간 이동 |
| 백스톱 | 최종 차단 / 최종 점검 | 다른 장치가 놓쳤을 때 마지막에 막는 것 |

### codemap leaf 항목 이름

leaf 규격의 항목 이름이 `함정:` → `주의사항:`으로 바뀐다. 이미 적어 둔 leaf는 고치지 않아도 된다 — codemap 스킬에 "이전 버전 leaf의 `함정:` 줄은 `주의사항:`과 같은 뜻이다. 그 leaf를 고칠 때 이름만 바꾼다"는 한 줄을 넣었다.
