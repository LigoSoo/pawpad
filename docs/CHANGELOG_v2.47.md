# CHANGELOG v2.47 — codemap 초기 부트스트랩 절차

> 날짜: 2026-08-10 | 기반: v2.46 | 스킬 수: **21 불변**
> 한 줄: 설치가 codemap 템플릿만 만들고 기존 코드베이스를 스캔하지 않던 공백을, codemap SKILL의 정식 절차로 메웠다.

---

## 1. 문제 (실관측)

PawPad 설치(`-Upgrade` 포함)는 `.claude/codemap/_index.md`를 **빈 템플릿으로만** 생성한다. codemap SKILL에는 증분 갱신 규칙("새 화면 만들면 INDEX에 추가")만 있고, **이미 코드가 쌓인 프로젝트에 처음 들어왔을 때 무엇을 해야 하는지가 없다.**

결과:

- 신규 도입 프로젝트는 codemap이 사실상 비어 있는 채로 운영된다.
- 심볼 lookup은 계속 miss → 에이전트가 소스를 통째로 스캔 → 토큰 2~3배.
- 사용자 체감은 "codemap이 프로젝트 시작부터 안 만들어진다".

실사례: **TeamPitch_2.0** — 2026-07-17 v2.46 설치. 배포본 자체는 정상(스킬 21종·훅·미러 md5 전량 일치)이었으나, 2026-08-10 시점 codemap은 role/권한 1개 도메인 5KB뿐이었다. `lib/` 실제 규모는 115개 dart 파일. 즉 **설치는 성공했는데 codemap만 계속 비어 있던** 상태가 3주 이상 지속됐다.

### 2-2. Phase B 전환 시 `_index.md` 경로 사멸 차단

trim-router로 전환하면 진입점이 `_root.md`로 바뀌는데, Session Protocol step7은 `_index.md`를 가리키고 있었다. 그대로 두면 **전환한 프로젝트의 ON START read가 죽는 파일을 향한다.**

- SKILL에 규약 명문화: `_index.md`는 삭제하지 않고 **라우팅 스텁**으로 남긴다(3~5줄 포인터 + "심볼표 없음, 통째 read 금지").
- Session Protocol step7 문구 수정 — `_root.md`(Phase B) 있으면 그것만, 없으면 `_index.md` MAP+HOT. 부트스트랩 제안 조건도 이 줄에 포함.

### A-2. 변경

#### 2-1. 로고 데이터 — 이미지 변환으로 교체

| 구성 | 내용 |

#### 2-2. `Show-PawBanner` — 프레임 스와핑 회전

```
프레임 그리기 (24줄, 각 줄 끝에 ESC[K)
  ↓ 180ms
ESC[24A 로 커서 되감기
  ↓
다음 프레임을 같은 자리에 덮어쓰기
```

기존 `Step-Begin`의 한 줄 제자리 갱신(CR)을 세로로 확장한 것이다. 새로운 의존성 없음.

- 시퀀스: `0..15` + `0` = 17장 → **1회전 후 0° 정면에 정착**. 총 16 × 180ms = **2.88s**.
- 각 줄 끝 `ESC[K`: 좁은 프레임(슬라이버)이 넓은 프레임 위에 덮일 때 남는 잔상 제거.
- 전 프레임 줄 수 **24 고정** — 되감기 `ESC[24A`가 줄 수에 의존한다. 프레임 재생성 시 반드시 유지.

#### 2-3. 폴백 (CI 로그 보존)

기존 `$script:uiLive` 게이트(비ANSI / `-ShowLog` / 리다이렉트)에 **창 높이 조건**을 추가했다.

- `[Console]::WindowHeight < 프레임 높이 + 12`이면 되감기가 스크롤과 엉켜 화면이 깨진다 → 애니메이션 생략.
- 폴백 시 0° 정지 프레임 1장만 출력. 리다이렉트된 로그에 escape 시퀀스가 섞이지 않는다.

### A-5. 재생성 절차

프레임을 다시 뽑아야 하면 — 변환기는 툴킷 배포물이 아니므로 규격만 남긴다.

1. 소스 `docs/icon.png`를 셀 단위로 샘플링(문자 셀은 세로로 약 2배 길다 → `Rows ≈ Cols / 2`).
2. alpha coverage + luma cut 0.35, 램프 ` .,:;~+*=%#@`.
3. 각도 `θ = 2πf/16`, 가로 배율 `cos(θ)`(절대값 0.07 하한, 부호 유지 = 뒷면 반전).
4. 급경사 각도에서 박스필터 반경이 폭주해 슬라이버가 소멸하므로 **블러 반경 상한 `width/24`** 필수.
5. 전 프레임을 최대 줄 수로 패딩한 뒤 `$script:pawFrames`에 반영하고, `Show-PawBanner`가 `$frames[0].Count`로 되감기 줄 수를 계산하는지 확인.

### 함정 기록

- **PowerShell 변수는 대소문자를 구분하지 않는다.** 파라미터 `$R`/`$C`와 루프 변수 `$r`/`$c`는 같은 변수라, `for ($r = 0; $r -lt $R; $r++)`가 `0 -lt 0`으로 즉시 종료된다(그리드 전량 null, 출력은 공백만). 변환기에서 `$GH`/`$GW` + `$y`/`$x`로 분리해 해소.
- PS5.1은 BOM 없는 UTF-8 `.ps1`을 ANSI로 읽는다. 프레임 데이터에는 non-ASCII가 없지만 `pawpad-setup.ps1`의 BOM은 유지해야 한다.
- 프레임 문자열은 작은따옴표로 감싼다. 램프에 `'`가 없으므로 이스케이프 불필요하고, here-string 종결자(`'@`)와 충돌하지도 않는다.
